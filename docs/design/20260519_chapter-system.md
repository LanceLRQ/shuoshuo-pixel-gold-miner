## 一、设计目标

把当前 10 关扩展到 **21 关 / 3 章节**，引入「**水晶宝石国 · 蟹守传说**」世界观。每章节有独特地形 / 主色调 / 收藏品，章末关有专属收藏品倾斜，章节切换有 ChapterScene 过场，**不引入 BOSS 关**（避免与 5 档难度系统数学冲突）。

---

## 二、世界观设定

**水晶宝石国**：粉色童话王国。年轻的「**猪猪公主**」继承了王位，与「**水晶蟹**」守卫军一起守护祖辈传下的水晶宝石宝藏。公主温柔呆萌、爱睡觉，整个王国氛围少女系。

矿工（玩家）跟着散落的水晶蟹甲碎片一路追查：

```
边境矿洞 ──→ 海湾蟹群 ──→ 粉色宫殿
 水晶矿坑    蟹潮海湾     猪猪王座
```

## 四、章节收藏品体系

| 章节 | 收藏品名 | 价值（NORMAL）| 像素规格 | 视觉设计 |
|------|---------|--------------|---------|---------|
| Ch1 | **水晶矿石** | 400$ | 6×6 | 半透明蓝晶 + 边缘高光 |
| Ch2 | **水晶蟹甲** | 800$ | 8×8 | 翠绿菱形甲壳 + 反光纹 |
| Ch3 | **猪猪粉宝石** | 1500$ | 10×10 | 粉色透明晶体 + 心形高光 + 闪光帧 |

### 设计意图

- **价值阶梯 400 / 800 / 1500**：与章节深入度同步上扬
- **命名格式一致**：「水晶矿石 / 水晶蟹甲 / 猪猪粉宝石」全是「材质+物件」结构，呼应「水晶宝石国」国名
- **叙事链路 "矿石 → 蟹甲 → 粉宝石"**：玩家集齐三件 = 隐藏图鉴目标（关联 Phase G #20 成就系统）
- **末关概率倾斜**：L7/L14/L21 末关 **+30% 概率出现章节收藏品**（矿物预算生成器最后强插 1 个，不破坏均匀分布）

## 六、章节过场（ChapterScene）

### 触发逻辑

```
进入新章节首关（L1 / L8 / L15）之前，插入 ChapterScene 过场
  ├─ 显示章名（大字）
  ├─ 显示剧情文字（一句）
  ├─ 停留 2.5 秒
  └─ 自动 → PLAYING
```

### 剧情文字定稿

| 章节 | 剧情文字 |
|------|---------|
| Ch1 水晶矿坑 | "矿工老王听说这里能挖到水晶宝石国的入口……" |
| Ch2 蟹潮海湾 | "传说海湾深处有水晶蟹守卫着前往王城的通道。" |
| Ch3 猪猪王座 | "粉色宫殿深处，猪猪公主抱着粉宝石打盹。" |

### UI 布局（800×540 横屏）

```
┌─────────────────────────────────────────────┐
│                                             │
│           [章节 LOGO 像素图 64×64]            │  y=140
│                                             │
│              【水晶矿坑】                      │  y=240（大字 LARGE）
│                                             │
│       "矿工老王听说这里能挖到水晶              │  y=320（中字 MEDIUM）
│            宝石国的入口……"                    │
│                                             │
│              [自动 2.5s 后跳过]                │  y=460（小字 SMALL）
│                                             │
└─────────────────────────────────────────────┘
```

### 跳过机制

- 按 Space / Enter / 鼠标点击 → 立即跳过进 PLAYING
- 2.5s 后自动跳过

## 七、猪猪公主角色定位

- **职责**：Ch3 场景背景吉祥物，无玩法交互
- **出现位置**：GameScene Ch3 关卡 BG 右侧（不挡矿物生成区）
- **像素规格**：32×32 像素，坐姿
- **主色**：粉色身体 `#FFB6C1` + 白色蕾丝围裙 `#FFF0F5` + 腮红 `#FF8FAB`
- **表情基础**：闭眼微笑（萌系少女向，**不戴王冠**）
- **动画**：**2 帧循环 —— 帧 A 闭眼微笑（基础态）/ 帧 B 睁眼眨眼**，约每 3 秒切换一次

- **彩蛋**：BGM 偶尔混入萌系猪叫（关联 Phase F 视听打磨）

export interface LevelConfig {
  level: number;
  targetMoney: number;
  mineralCount: number;

## 九、与现有系统的兼容性

| 系统 | 影响 | 处理 |
|------|------|------|
| 5 档难度系统 | 关卡时间/金额都按 `difficultyConfig.valueScale × timeScale` 缩放 | **无需改动**，难度系统与章节正交 |
| 矿物预算驱动生成器 | 章节收藏品需要在末关 +30% 倾斜插入 | 在 GameScene `generateMinerals()` 末尾追加章节收藏品逻辑 |
| 11 槽位存档系统 | 存档需记录当前关卡和章节（章节可从关卡推导，不存独立字段） | **无需改动**，从 level 推导 chapter |
| HUD 显示 | 增加章节标识"水晶矿坑 · L3/7" | 改 `src/ui/HUD.ts` 加 chapterLabel |
| INFINITE 模式 | RESULT 直跳 PLAYING，不应触发 ChapterScene | 在 ChapterScene 触发逻辑前加 `!difficultyConfig.infiniteItems` 守卫 |
