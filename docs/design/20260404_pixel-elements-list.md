# 黄金矿工 - 像素素材清单

> **本文档**：当前游戏中**已实现**的像素精灵清单，标注尺寸、文件位置和可替换性
>
> **像素机制**：所有精灵定义为 `PixelMap`（二维颜色数组），颜色用 `#RRGGBB`，透明用 `0`
> 运行时通过离屏 Canvas 预渲染缓存为 `HTMLCanvasElement`，再用 `drawImage` 复用
>
> **替换方法**：
> 1. **就地修改**：编辑 `src/assets/sprites.ts` 中对应的 const 数组（最直接）
> 2. **新主题**：在 `src/assets/theme/` 新建主题文件，通过 ThemeManager 注册（不动核心）
> 3. **图片转换**：用 `tools/pixel-converter.html` 把 PNG 转成 PixelMap 数组

## 七、主题系统（精灵集打包）

主题 = 完整精灵集 + 背景色板。切换主题=换皮，不动核心数据。

| 主题 ID | 文件 | 说明 |
|---------|------|------|
| `classic` | `theme/classic.ts` | 经典原味（默认）|
| `shuoshuo-crystal` | `theme/shuoshuo-crystal.ts` | 水晶风（备选）|

**添加新主题步骤**：
1. 在 `src/assets/theme/` 新建文件，导出 `ThemeDefinition`
2. 在 `src/core/Game.ts:108` 附近 `this.themeManager.register(YOUR_THEME)`
3. 玩家可在设置页切换（持久化到 localStorage，由 `restoreTheme()` 启动恢复）

## 十一、像素素材规范

- **颜色**：`#RRGGBB` 字符串，透明用 `0`（数字零）
- **命名**：UPPER_SNAKE_CASE（如 `MINER_IDLE` / `GOLD_SMALL`）
- **尺寸**：宽 × 高，行优先（外层数组=行，内层数组=列）
- **配色**：颜色常量提取到模块顶部，避免硬编码到 PixelMap 内
- **章节收藏品**：精灵尺寸建议 6×6 / 8×8 / 10×10 / 12×12 递进（呼应价值阶梯）
