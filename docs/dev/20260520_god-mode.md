# 上帝模式调试入口（God Mode）

浏览器控制台 `window.god` 对象，提供切关卡 / 设金额 / 发道具 / 切场景等调试命令。

## 启用条件

| 模式 | 是否启用 |
|---|---|
| dev（`pnpm run dev`） | ✅ 自动启用，控制台打印 `[GOD MODE]` banner |
| prod（`pnpm run build`） | 默认 ❌ 不暴露；仅当 web root 存在 `whoisyourdaddy.html`（HEAD 返回 200）时启用 |

**prod 临时开启方法**：往部署目录放一个空 `whoisyourdaddy.html`，刷新页面即生效；用完删除该文件即关闭。

## 命令速查

```js
god.help()                      // 打印所有命令
god.state()                     // 当前 state / level / money / items / difficulty / theme

// 关卡
god.level(15)                   // 切到第 15 关（在 GameScene 中立即重载）
god.level()                     // 打印当前关
god.nextLevel()                 // 下一关
god.skipToCh(2)                 // 跳到章节起点（1→L1, 2→L8, 3→L15）

// 金额
god.money(99999)                // 设置当前累计金额
god.money()                     // 打印当前金额
god.addMoney(500)               // 增加/减少金额

// 道具（id 大小写不敏感）
god.give('DYNAMITE')            // 发指定道具
god.giveAll()                   // 一次发齐 8 个道具
god.clearItems()                // 清空所有道具
god.items()                     // 打印已有 + 所有可用 itemId

// 场景 / 难度 / 主题
god.scene('SHOP')               // 切场景（MENU / PLAYING / SHOP / RESULT / GAME_OVER / ...）
god.difficulty('EXPERT')        // 切难度
god.theme('classic')            // 切主题；不传 = 列出所有
```

## 实现位置

- `src/dev/godMode.ts` — 主模块（探针 + 命令实现）
- `src/main.ts:23` — 启动时动态 import 调用 `setupGodMode(game)`
- `src/core/Game.ts:setCurrentMoney` — 同步 HUD 用

## 安全考虑

- cheat 只影响该用户自己浏览器的游戏状态，无服务端数据
- 探针文件名 `whoisyourdaddy.html` 是约定，部署者可任意改名（修改 `godMode.ts` 里硬编码字符串）
- dev 路径通过 `import.meta.env.DEV` 静态分析，`vite build` 时 dev 分支会被 Tree-shake 掉
